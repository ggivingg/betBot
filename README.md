# betBot

Whatsapp bot to collect inputs of peoples bets on the spreads during sporting
events (starting with football) and then when all the bets are in -
automatically adding to a chart on a github page that tracks this weeks bets,
later it updates standings based on when games complete. calculates weekly
standings, combines weekly standings into season standings for bettors and
combines season standings into total standings. it keeps a chart in the website
that shows who has won each week; there is a chart by season (we will give that
data) 

# tools
- astro
- whatsapp bot
- tailwind
